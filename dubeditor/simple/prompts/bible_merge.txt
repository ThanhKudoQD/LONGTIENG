==================================================
CHARACTER MERGE RULES
=====================

For each Chinese name appearing in multiple parts:

* Keep ONE entry under the original Chinese name as key.
* Sino-Vietnamese name: pick the most CORRECT version
  (Sino-Vietnamese accuracy is critical — don't accept obvious mistakes).
* Gender: prefer non-U if conflict.
* Importance: if ANY part says "core" → master = "core".
* Aliases: UNION across parts, deduped.

If two parts have different Chinese names but clearly refer to the same person
(e.g. one part used an alias as the canonical key):

* Merge into the canonical Chinese name,
* Move the alias-as-key version into aliases.

==================================================
ALIAS CONFLICT RESOLUTION
=========================

If the same alias appears under multiple different characters:

* The alias is ambiguous → REMOVE from all characters.

Keep an alias only if it clearly belongs to one character.

==================================================
SPEECH STYLE MERGE
==================

For each character with speech in multiple parts:

* Rewrite into ONE coherent description that captures all observed styles.
* Don't say "in part 1 ... in part 2 ..." — produce a unified style.

Example:
* Part A: "nũng nịu khi với chị"
* Part B: "sắc bén khi đối đầu"
→ Master: "nũng nịu với chị, sắc bén khi đối đầu, đa diện"

==================================================
RELATIONSHIP MERGE
==================

Union all "r" pairs.

If same pair has different "xưng_hô" across parts:

* If one is intimate (em/chị) and another is hostile (cô/tôi):
  → keep the MORE COMMON or the LATER one (relationship evolution).
* If unclear, pick the dialogue-natural option.

Same for "dynamics".

==================================================
GLOSSARY MERGE
==============

Union all "t" entries.

If same Chinese term has different Vietnamese translations:

* Pick the most natural / fandom-correct version.
* Prefer translations from parts with more context.

==================================================
RULES MERGE
===========

Dedupe semantically (not by string).

Example:
* "Dịch tự nhiên"
* "Dịch giản dị, tự nhiên"
→ Keep ONE.

Max 8 rules in master.

==================================================
SUMMARY MERGE
=============

Combine part summaries into ONE film-level summary.

* Don't paste in sequence.
* Rewrite as 2-3 connected sentences capturing the main plot arc and core characters.
* Max 1000 Vietnamese characters.

==================================================
UNKNOWNS MERGE
==============

Union all unknowns. Dedupe by "raw".

If same "raw" has different "guess" across parts:

* Pick the most common guess,
* Or merge guesses if compatible.

cat = "tu_xung" — TỰ XƯNG (cách nhân vật tự gọi mình):
  - 朕 → "trẫm" (Hoàng đế tự xưng)
  - 本宫 → "bản cung" (phi tần/hoàng hậu tự xưng)
  - 本王 → "bản vương" (vương gia tự xưng)
  - 哀家 → "ai gia" (thái hậu tự xưng)
  - 臣妾 → "thần thiếp" (phi tần xưng với vua)
  - 奴婢 → "nô tỳ" (cung nữ/nô tì tự xưng)
  - 奴才 → "nô tài" (thái giám/nô bộc nam tự xưng)
  - 贫道 → "bần đạo" (đạo sĩ tự xưng)
  - 在下 → "tại hạ" (võ hiệp tự xưng)

cat = "chuc_vu" — CHỨC VỤ / DANH XƯNG:
  - 皇上 → "hoàng thượng"
  - 陛下 → "bệ hạ"
  - 皇后 → "hoàng hậu"
  - 贵妃 / 贤妃 / 淑妃 → quý phi / hiền phi / thục phi
  - 太后 → "thái hậu"
  - 娘娘 → "nương nương"
  - 公公 → "công công" (thái giám lớn tuổi)
  - 嬷嬷 → "ma ma" (nữ bộc lớn tuổi/vú nuôi)
  - 大人 → "đại nhân"
  - 总裁 → "Tổng giám đốc"
  - 顾总 → "Cố tổng" (suffix sau họ)
  - 大侠 → "đại hiệp"
  - 师父 / 师兄 / 师妹 → "sư phụ" / "sư huynh" / "sư muội"
  - 掌门 → "chưởng môn"

cat = "dia_danh" — ĐỊA DANH / TỔ CHỨC riêng phim:
  - 顾氏集团 → "Tập đoàn Cố Thị"
  - 凤栖宫 → "cung Phượng Hoa"
  - 御花园 → "ngự hoa viên"
  - 江湖 → "giang hồ"
  - 武林 → "võ lâm"

  - 宠幸 → "sủng hạnh" (vua sủng ái phi tần qua đêm)
  - 侍寝 → "thị tẩm" (hầu hạ vua ngủ)
  - 圣旨 → "thánh chỉ"
  - 懿旨 → "ý chỉ" (Lệnh thái hậu/hoàng hậu)
  - 打入冷宫 → "đày vào lãnh cung"
  - 渡劫 → "độ kiếp"
  - 元婴 / 金丹 → "nguyên anh" / "kim đan"

cat = "cliche" — CỤM TỪ ĐIỂN HÌNH (>4 chữ, lặp lại nguyên cụm):

  - 本宫今日就让你知道 → "Hôm nay bản cung sẽ cho ngươi biết"
  - 退下 → "Lui xuống"
  - 来人 → "Người đâu"
  - 拖出去 → "Lôi ra ngoài"
  - 你好大的胆子 → "Ngươi to gan thật"

  - Khái niệm không rõ category
